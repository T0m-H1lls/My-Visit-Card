            Пометки:
    <strong> — жирный (важность).
    <b> — просто жирный (без смысла).
    <em> — курсив (акцент).
    <i> — просто курсив.
    <mark> — жёлтая подсветка (выделение).
    <u> — подчёркивание.
    <del> — зачёркнутый (удалённый текст).
    <sub> — нижний индекс (H2O — вода).
    <sup> — верхний индекс (x²).


            3.5. Код и цитаты
    <code> — код в тексте (моноширинный шрифт).
    <pre> — «предварительно отформатированный» текст: сохраняет все пробелы и переносы.
    <blockquote> — длинная цитата-блок.
    <q> — короткая цитата внутри строки.

            6. Таблицы
    Таблицы строятся из строк и ячеек. Основные теги:

    <table> — сама таблица.
    <tr> — строка (table row).
    <th> — ячейка-заголовок (table header).
    <td> — обычная ячейка (table data).
    <caption> — подпись таблицы.
    <thead> — «шапка» таблицы (группа строк-заголовков).
    <tbody> — основное тело таблицы.
    <tfoot> — «подвал» таблицы.

                 Поле ввода <input>
    <input> — одиночный тег. Его тип задаётся атрибутом type.

    <input type="text" name="username" placeholder="Введите имя">

    Атрибуты:

        type — тип поля (ниже).
        name — имя поля, важное для отправки данных (данные уходят как пары «имя=значение»).
        placeholder — серый подсказочный текст внутри поля, исчезает при вводе.
        value — значение по умолчанию.

        Основные типы type:

        Тип     	Что делает
        text	    Обычное текстовое поле
        password	Поле для пароля (точки)
        email	    Проверяет, что введён e-mail
        number	    Поле для чисел (со стрелками)
        tel	        Поле для телефона
        date	    Выбор даты из календаря
        checkbox	Галочка (может быть отмечена)
        radio	    Переключатель (один из группы)
        file	    Выбор файла
        submit	    Кнопка отправки
        reset	    Кнопка сброса
        button	    Обычная кнопка


        10.1. Аудио <audio>

    <audio controls>
        <source src="music.mp3" type="audio/mpeg">
        Ваш браузер не поддерживает аудио.
    </audio>
    Текст между тегами показывается, если браузер audio не поддерживает.


    Атрибуты audio:

    controls — показать панель управления (play, pause, громкость).
    autoplay — начать воспроизведение автоматически.
    loop — повторять в цикле.
    muted — выключить звук по умолчанию.



                10.2. Видео <video>
    <video controls width="640" height="360" poster="preview.jpg">
        <source src="movie.mp4" type="video/mp4">
        Ваш браузер не поддерживает видео.
    </video>

    Атрибуты video:

    controls — панель управления.
    poster — картинка-заставка до начала воспроизведения.
    width / height — размер.
    autoplay, loop, muted — аналогично аудио.
    ℹ️ Форматы: аудио обычно .mp3, .ogg, .wav; видео — .mp4, .webm, .ogg. Разные браузеры поддерживают разные форматы, поэтому часто указывают несколько <source>.
